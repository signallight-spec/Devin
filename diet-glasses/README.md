# やせる眼鏡 (Diet Glasses) — プロトタイプ

カメラ映像から食べ物をリアルタイム認識し、1日の摂取カロリーを自動累計。
規定値（上限）を超えた状態で食べ物が視界に入ると、画面に赤い「禁止」スタンプを重ねて表示するAR眼鏡のソフトウェア・プロトタイプです。

## 動かし方

```bash
cd diet-glasses
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

- **カメラ**: カメラへのアクセス許可が必要です（localhost または HTTPS で動作）。スマホでは背面カメラを使用します。
- **デモモード**: カメラが無い環境では自動でデモモードに入ります（右上のボタンで切替）。同梱のサンプル画像（寿司・ラーメン・バーガー・おにぎり・カレー・デスク）が順に表示され、同じ認識パイプラインを通ります。

## 仕組み

| 処理 | 実装 |
|---|---|
| 食品認識 | OpenAI CLIP (ViT-B/16, 量子化ONNX) をブラウザ内で実行 — transformers.js のゼロショット画像分類。約1.4秒ごとにフレームを評価 |
| カロリー推定 | 食品ごとの「1人前」kcalを内蔵テーブルで概算（量の推定は未実装 — プロトタイプの精度上の限界） |
| 日次累計 | localStorage に当日の食事ログを保存。同一食品の連続検出(2フレーム)で自動記録 + 手動記録ボタン、90秒クールダウン |
| 禁止表示 | 累計 ≥ 上限で、検出した食べ物の上に赤い「禁止」スタンプ＋赤いビネットを表示。80%で警告帯 |

## プロトタイプの限界 / 実プロダクト化に向けて

- カロリーは「種類→1人前」の概算。実際の量（g）は推定していません。精度向上には深度推定 or マルチフレームでの体積推定、または食品DBとの照合が必要です。
- 現在は画像分類のみで位置情報なし（禁止マークは画面全体に表示）。食品の位置に追従させるには物体検出モデル（YOLO系等）への置換が必要です。
- 「見た=食べた」ではないため、実用では食事開始・終了の判定（噛む動作、時間経過、手動確認UI等）が必要です。
- 実際のグラスデバイス（Xreal / Rokid / Ray-Ban Meta Display 等）への移植は、各社SDKのカメラ・表示APIにこのロジックを載せる形になります。
